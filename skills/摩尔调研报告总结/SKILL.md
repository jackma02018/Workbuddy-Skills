# 摩尔调研报告总结

**一句话定位**：把一份已完成的摩尔现场调研报告（docx），按用户给定的「总结模板」骨架，压缩提炼成一份纯文本 TXT 总结——只换内容、不动结构。

**与相邻技能的分工（避免口径冲突）**
- `摩尔调研报告整理`：从**零散资料**（访谈/纪要/照片）成稿**完整五章 docx 调研报告**。本技能在它**之后**使用——对已成稿的 docx 再做精简提炼。
- `mes-customer-research-report`：素材解析与约 200 字项目总结；本技能产出的是**套用固定模板结构**的较长总结，不以它的口径为准。
- `摩尔结构化方案编写`：调研结论转 PPT/专题方案；本技能只做**文本级提炼**，不转方案。

---

## 一、触发条件

### 必触发
- 用户提供一份已完成的调研报告 `.docx`（如 `<客户> MES 系统建设现场调研报告_<YYYYMMDD>.docx`）+ 一份「调研报告总结模板」`.txt`，要求「按模板提炼 / 总结 / 生成总结 TXT」。
- 用户要求把一份摩尔调研报告（docx）压缩/提炼成纯文本总结，并指定了章节结构或模板。
- 用户明确要求「把调研报告总结成 txt」「生成调研报告总结文件」。

### 不触发（改走其他技能）
| 场景 | 去向 |
|---|---|
| 从零散资料成稿完整五章 docx 调研报告 | `摩尔调研报告整理` |
| 调研结论做汇报 PPT / 专题方案 | `摩尔结构化方案编写` |
| 纯素材理解、约 200 字项目总结、错别字质检 | `mes-customer-research-report` |

## 二、输入文件要求

| 类别 | 必需性 | 说明 |
|---|---|---|
| ① 调研报告 `.docx` | **必需** | 已完成的现场调研报告。本机无 `python-docx` 且 pip 不可用，用标准库 `zipfile` 提取 `word/document.xml` 文本（见 §六）。 |
| ② 总结模板 `.txt` | **强烈推荐** | 规定章节标题、字段名称、编号顺序、标点（全/半角冒号）的总结骨架。**提供则严格遵循其结构、字段名、顺序、格式**；不提供时用 §四 内置默认结构。 |
| ③ 输出命名/路径 | 默认 | 默认文件名 `<客户简称> MES 系统建设现场调研报告.TXT`，保存到与所读取调研报告**相同目录**；模板或用户另有命名要求时从其要求。 |

**零编造与缺失处理**
- 数字、人名、系统正式名称、设备型号、具体日期：只能来自调研报告原文；报告没有对应内容时，不在该字段硬凑，按模板留空或写「本次报告未载明」（仅当模板该字段本就允许状态标注时）。
- 模板有字段但报告未明示（典型如「竞争对手」）：映射报告中可核验的「现有 ERP 厂商 / 在用系统供应商」等事实填入；**不编造第三方竞品**；确无任何依据则标注「本次报告未载明」。
- 专有名词（MES/QMS/WMS/ECN/SOP/Andon 等）、系统名（如金蝶云星辰）、人名、日期、项目名称须与原文**逐字一致**。

## 三、执行步骤

| Step | 动作 | 关键约束 |
|---|---|---|
| 0 | 建立任务清单（≥4 步） | 只读任务，不改报告原文 |
| 1 | 用 `zipfile` 提取调研报告 docx 全文文本 | 拼接 `<w:t>` 标签内容，按 `</w:p>` 保留段落换行；注意 `xml:space` 与转义实体 |
| 2 | 读取总结模板 txt，解析其**章节标题 / 字段名 / 编号顺序 / 标点格式**（全角或半角冒号以模板为准），原样记录骨架 | 禁止改模板的章节名、字段名、顺序、编号样式 |
| 3 | 通读报告，按模板每个字段从报告中抽取对应事实 | 结论先行、简洁；只写报告中已出现的事实 |
| 4 | 逐字段撰写：先结论再展开；专有名词/日期/系统名/人名与原文一致 | 不新增模板外章节；不虚构、不主观扩展 |
| 5 | 处理「竞争对手」等模板有但报告未明示的字段 | 见 §二 缺失处理，映射可核验事实，不编造竞品 |
| 6 | 生成纯文本 TXT，命名与路径见 §五 | 纯文本，无 Markdown/HTML 渲染标记（除非模板本身含） |
| 7 | 回读校验：章节/字段/顺序/标点与模板一致，关键事实与原文一致，无新增章节，无占位符 | 有偏差必须修到一致 |

## 五、输出格式规范

- **格式**：纯文本 `.TXT`，无 Markdown/HTML 渲染标记（除非模板本身含标记）；编码 UTF-8。
- **结构严丝合缝**：章节标题文字、字段名称、编号（一/二/三…、1、2、3…）、顺序、标点（全/半角冒号以模板为准）逐字沿用模板；不增删章节、不改字段名、不调顺序。
- **文件名**：默认 `<客户简称> MES 系统建设现场调研报告.TXT`（与本次任务一致）；模板或用户另有命名要求从其要求。
- **保存路径**：与所读取的调研报告 `.docx` **相同目录**。
- **内容纪律**：不新增模板外章节；不虚构或主观扩展信息；关键事实（项目名称、系统名称、日期、专有名词）与原文一致；结论先行、简洁。

- docx 文本提取参考片段：
  ```python
  import zipfile, re
  with zipfile.ZipFile(path) as z:
      xml = z.read('word/document.xml').decode('utf-8')
  paras = re.split(r'</w:p>', xml)
  lines = [''.join(re.findall(r'<w:t[^>]*>(.*?)</w:t>', p, re.S)) for p in paras]
  text = '\n'.join(lines)
  ```
