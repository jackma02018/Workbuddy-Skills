# 提示词模板（下次直接复制）

## 模板 A：完整流程（一次做完合并 + 缩放 + 文字自适应）

```
用「摩尔多页PPT合并」技能，把下面几份单页方案合并到《摩尔元数方案模版.pptx》：

- 模版：F:\01MOM售前知识\04方案AI编写\摩尔AI方案整理\摩尔元数方案模版_原单页备份.pptx
- 方案（按此顺序）：
  1. 读写分离改造方案.pptx
  2. 大批量表报分析数据导出读写分离方案.pptx
  3. 上传设计原型图智能体生成页面代码.pptx
  4. 图纸数据自动提取结构化输出方案.pptx
- 输出：BOM售前方案合集.pptx

要求：
1. 字体统一黑体，标题 20 号、正文 12 号；
2. 每页内容整体合并为一个对象后整体等比缩小，缩放比 0.85；
3. 缩小与合并过程中必须保留每页标题文字，以及页面右侧的摩尔元数公司图标，
   这两项始终可见、不被合并、不被遮挡；
4. 文字必须在容器边界内：超框就自动缩小字号，仍超框就减少字数（尾部补 …），
   不允许溢出，也不允许压住右上角 Logo；
5. 改完给我图片完整性（零缺失）与每页缩放比的校验结论；
   本机没有 PowerPoint/WPS，若未做 Office 端渲染验收要如实说明。
```

## 模板 B：只做「整页合并为一个对象 + 等比缩小」

```
用「摩尔多页PPT合并」技能，对《XXX.pptx》每一页：
先把页面内所有内容整体合并为一个对象，再整体等比缩小到 0.85；
合并与缩小过程中保留每页标题文字和右侧的摩尔元数公司图标，确保始终可见、不被合并或遮挡。
封面页不参与处理。改完用图片 sha1 校验零缺失，并给出每页缩放比。
```

## 模板 C：只做「文字自适应容器」

```
用「摩尔多页PPT合并」技能，检查《XXX.pptx》每页标题区文字：
凡超出容器边界或压到右上角 Logo 的，先自动缩小字号（下限 12 号），
仍超出就减少字数并在尾部补省略号；
然后启用「溢出时自动缩小文字」，保证以后改字也不会出格。
```

## 模板 D：空白页按封面版式重建

```
用「摩尔多页PPT合并」技能，参考第 1 页的版式，把第 N 页空白页按封面布局重建
（左上标题占位 + 左侧圆点弧线装饰 + 右上角摩尔元数 Logo），
标题先用占位文字；标题文字要自适应容器，改字后不会溢出或压住 Logo。
```
