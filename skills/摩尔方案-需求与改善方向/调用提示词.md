## A. 完整版（推荐，首次调用用这个）

```
使用「摩尔方案-需求与改善方向」技能处理以下客户需求。

【客户】{江阴旺达电子}
【资料目录】{E:\02跟进项目\无锡-江阴旺达电子有限公司-电子组装-LED控制器电源充电器-202609}
【交付格式】PPT
【模板】{E:\02跟进项目\摩尔方案模板.potx}
【模块与顺序】{生产计划管理 → 仓库管理 → 生产管理 → 品质管理 → 设备管理}
【深度】standard

请严格按技能的六阶段执行：
① 需求接收与澄清 → ② 信息收集与整理（完整读取目录下全部资料，含 xlsx 与图片，不抽样）
→ ③ 缺失信息追问（区分致命缺失与可假设缺失，仅致命缺失才停下来问我）
→ ④ 需求归类与优先级判断（给出打分理由，不许全部标 P0）
→ ⑤ 方案方向输出（每模块四层：业务需求 / 当前痛点带基线 / 改善方向双视角 / 方案价值）
→ ⑥ 文档命名与归档（YYYYMMDD_{客户简称}.pptx，落到源资料同目录）

约束：
- 未在资料中找到依据的数字一律标「待确认」，禁止估算后当事实写；
- 每条改善方向必须可检验，禁止写「加强管理」这类空话；
- 行业缩写（SMT/BOM/ERP/FIFO/ECN/Andon/IQC）保留；
- 相邻模块的思维类型不重复，全套覆盖系统思维 / 数据驱动思维 / 精益思维；
- 交付前过 8 项校验清单并逐项向我报告；
- 若目标文件被 WPS 占用（存在 ~$ 锁文件），另存新版本号，不要强删或结束我的进程。
```
