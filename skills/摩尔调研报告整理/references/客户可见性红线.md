# 客户可见性红线（净化与修订对照表）

> 报告是给客户看的正式交付件。凡是暴露「资料怎么来的、我们怎么整理、怎么按意见改稿」的字句，一律不进文档。
> 本文件汇集目标成果基线件形成过程中的 5 轮修订，后续整理同类报告时**从初稿起就按此口径写**，不要先写再删。

## 一、禁用词总表（交付文档中 0 命中）

| 类别 | 禁用字眼 | 中性替代表述 |
|---|---|---|
| 资料来源 | 录音、原文转写、转写稿、听记、钉钉 AI 听记、纪要、源文件、4 份源文件、两段录音、资料基础 | 本次现场调研、现场调研记录（作为事实来源说明时尽量省略整句） |
| 内部定位 | 时间码、发言人 1/2/3、发言人编号 | 调研环节、议题（**仅内部底稿使用，交付文档不出现**） |
| 引述口径 | 口述、复述、录音转写作「X」 | 客户介绍、现场亦称「X」、客户提出的计划目标 |
| 证据体系 | `[E-xxx]`、`E-xxx` 正文标注、附：证据索引、证据索引表、证据编号 | 无（正文不显示标注，也不输出索引附录） |
| 对话痕迹 | 按客户要求、按要求、本次修订、上一版、根据意见 | 直接陈述最终事实，不加成因说明 |
| 元说明 | 见 §三 精确清单 | 直接删句，或收束标点后保留业务事实 |
| 占位符 | XXXXXX、XX有限公司、TBD、待填写、待补充 | 「本次资料未载明」或无该字段 |

**校验范围**：正文段落、所有表格单元格、表注、附录、自检清单、**页脚**（页脚最易漏）。

## 六、规则与表述分离（最易踩的坑）

被删的元说明句所对应的**行为约束仍然 100% 有效**，只是不得写成报告里的自述句：

| 被删的句子 | 仍需遵守的约束 |
|---|---|
| 本报告不推断具体人名 | 只按岗位/团队填责任人 |
| 本报告不据此推算产能 | 不把经营目标当产能、不推算产能 |
| 同一事实只在一处陈述 | MECE 编写，跨部门事项归 3.10/3.11 |
| 客户工商全称本次资料未载明 | 不擅自补「有限公司」 |
| 按客户要求… | 直接给最终版本，不解释改稿原因 |
