# 方案_图片批量命名

## 一、功能概述
把指定文件夹中的图片逐张进行视觉内容识别，匹配到给定类别之一，复制（保留原图不动）并按「类别_序号」重命名输出到新目录；无法明确归类的图片保留原文件名复制；最终产出分类对照清单。可选子能力：依据表单名称缩写规则对带名表单做规范化，并输出更改前后对照清单。

本技能封装了一次完整的图片批量命名项目工作流，把「缩略图降采样 → 分批视觉识别 → 归类映射 → 复制重命名 + 清单 → 可选表单名规范化」固化为可重复执行的步骤与脚本。

## 二、适用场景 / 触发条件
- 用户有一批未整理的现场照片（工厂参观、客户调研、车间巡检、设备拍照、看板/标签留档等），需要按场景/看板/标签/表单等维度归类重命名。
- 用户明确点名本技能，或描述「批量识别图片并按类别命名 / 归类重命名 / 生成对照清单」等意图。
- 要求不改变原图、只产出规整后的副本与清单。
- 触发后，**优先调用本技能**完成，而不是从零写一次性脚本。

## 三、核心输入
| 输入项 | 必填 | 说明 |
|---|---|---|
| 图片文件夹路径 | 是 | 待处理图片所在绝对路径目录 |
| 类别清单 | 否 | 归类类别列表；缺省使用内置《默认类别清单》（见 `references/default_categories.md`） |
| 输出目录 | 否 | 分类结果目录；缺省为 `<源文件夹>_已分类`（与源同级） |
| 保留原图 | 强制 | 始终复制副本，绝不移动/删除/覆盖原图 |
| 表单名称规范化 | 否 | 默认关闭；开启后按《表单名称缩写规则》处理带名表单并输出对照清单 |

## 四、处理步骤
1. **环境准备**：确保可用 Python + Pillow（必要时在隔离 venv 安装）。调用 `scripts/downscale.py` 把原图统一缩放到长边约 1000px 生成缩略图目录，降低逐张视觉识别的上下文开销（脚本不改动原图）。
2. **逐批视觉识别**：分批读取缩略图（建议一次 10–12 张），识别每张内容，匹配到类别清单中最贴切的一项；同一照片内容既可归入场景类（如 SMT车间）也可归入表单类时，优先按用户清单的细化类别。
3. **归类映射**：汇总为 `原文件名 → 类别` 映射；无法归入任何类别的标记为空（保留原名）。同类多张追加 `_1/_2/...` 序号，序号从 1 开始。
4. **复制重命名**：调用 `scripts/apply_classification.py` 读取映射，将**原图**复制（非移动）到输出目录，按 `类别_序号.扩展名` 重命名；未归类项保留原文件名。脚本同时生成 `分类对照清单.csv`（列：新文件名, 类别, 原文件名, 图片内容说明）。
5. **（可选）表单名称规范化**：若开启，调用 `scripts/normalize_forms.py` 读取 `分类对照清单.csv`，按 `references/form_abbrev_rules.md` 的规则对带名表单做规范化，输出 `表单名称规范化对照清单.csv`（列：序号, 类别, 原表单名称, 新表单名称, 是否更改, 语义类别, 原文件名）。
6. **交付**：通过 `present_files` 呈现输出目录与清单文件，并在回复中给出分类统计与关键说明。

## 五、输出格式
- **已分类图片集合**：输出目录下，按 `类别_序号.jpg`（或保留原名）命名的副本；原图保持不变。
- **分类对照清单.csv**（UTF-8 BOM，Excel 可直接打开）：`新文件名, 类别, 原文件名, 图片内容说明`。
- **（可选）表单名称规范化对照清单.csv**：`序号, 类别, 原表单名称, 新表单名称, 是否更改, 语义类别(首件检验/ECN/NCR), 原文件名`。

## 六、表单名称规范化（可选子能力）
仅对「带具体表单名的记录」生效（检验报告/记录表/统计表/日报表/追踪表/确认表/保养卡/管理表等），场景照、看板、标签、客户需求等不在范围。规则见 `references/form_abbrev_rules.md`。典型处理：首件检验→加 `[FAI]`；ECR 视作 ECN 同类（`ECR`→`ECN`）；IQC/IPQC/FQC 代号保留；后缀统一（记录表/统计表/日报表/追踪表/确认表），并修正明显错别字。语义定位 `首件检验 / NCR / ECN` 三项，NCR 无对应照片时标注「待补」。此步骤仅改表单名显示，不改文件夹/类别结构与任何业务数据。

## 七、参考与脚本
- `references/default_categories.md`：内置默认类别清单（制造/MOM 行业）及扩展说明。
- `references/form_abbrev_rules.md`：表单名称缩写/规范化规则详表。
- `scripts/downscale.py`：原图 → 缩略图（参数化：--src --dst --max-edge）。
- `scripts/apply_classification.py`：按映射复制重命名 + 生成对照清单（参数化：--src --dst --mapping）。
- `scripts/normalize_forms.py`：表单名称规范化 + 更改前后对照清单（参数化：--manifest --out [--rules --semantic]）。

### 使用示例
**示例 1（最简，默认类别）**
> 请用 方案_图片批量命名 技能，处理 `E:\项目A\客户资料\车间照片` 下的全部图片，按默认类别归类，输出到同级 `车间照片_已分类` 目录，保留原图不动。

**示例 2（自定义类别 + 开启表单规范化）**
> 用 方案_图片批量命名 处理 `D:\调研\产线照片`，类别清单为：SMT车间、DIP车间、仓库、IQC、IPQC、FQC、生产看板、设备；并开启表单名称规范化，按 MOM 缩写规则输出对照清单。

**示例 3（仅归类 + 对照清单）**
> 把 `C:\拍照\工厂参观` 里的图片识别归类并重命名，原图不要动，最后给我一份「新文件名 ↔ 原文件名」的对照清单。

**示例 4（带映射文件的程序化调用）**
> 用 方案_图片批量命名 的 apply_classification 脚本，按 `mapping.json`（`{"IMG_001.jpg":"SMT车间","IMG_002.jpg":""}`）把 `D:\raw` 的原图复制到 `D:\out`，并生成 `分类对照清单.csv`。
