# 表单名称缩写 / 规范化规则

对「带具体表单名的记录」（检验报告 / 记录表 / 统计表 / 日报表 / 追踪表 / 确认表 / 保养卡 / 管理表 等）执行规范化。**场景照、看板、标签、客户需求等不在范围内**。

> 适用范围：仅改表单名显示与标识；不改文件夹/类别结构、不改任何业务数据与原始图片。

## 一、英文质量代号
| 规则 | 处理 | 示例 |
|---|---|---|
| 首件检验 | 追加 `[FAI]` 代号 | 首件检验记录表 → 首件检验记录表[FAI] |
| ECR 视作 ECN 同类 | `ECR` 改为 `ECN`（工程变更统一归口） | ECR变更追踪表 → ECN变更追踪表 |
| IQC / IPQC / FQC | 已是标准代号，保留不增删 | IQC加严抽样动态追踪表（不变） |

## 二、后缀统一规范
保持标准后缀写法，不随意缩略：
- 记录表 / 统计表 / 日报表 / 追踪表 / 确认表 —— 维持原样（已是规范写法）。
- 仅有「记录」缺「表」的，补全为「记录表」：产品点检记录(电性测试) → 产品点检记录表(电性测试)。

## 三、错别字修正
| 原 | 修正 |
|---|---|
| 管理制表 | 管理表（红胶储存/使用管理制表 → 红胶储存/使用管理表） |
| 源料 | 原料（IQC源料状态 → IQC原料状态，明显笔误时修正） |

## 四、语义定位（首件检验 / NCR / ECN）
- **首件检验**：定位到首件检验记录表（通常落在 IPQC检验表单），标注语义类别「首件检验」。
- **ECN**：工程变更类；若原图实为 ECR 变更追踪表，按规则归入 ECN 并修正名称；ECN 名称不得残留末尾多余空格。
- **NCR**：不合格品报告类；当前照片若无对应项，在对照清单标注「待补」，不强行虚构。

## 五、典型更改示例（前后对照）
| 原表单名称 | 新表单名称 | 备注 |
|---|---|---|
| 首件检验记录表 | 首件检验记录表[FAI] | 加 FAI 代号 |
| 产品点检记录(电性测试) | 产品点检记录表(电性测试) | 补「表」字 |
| ECR变更追踪表(IQC源料状态) | ECN变更追踪表(IQC原料状态) | ECR→ECN；源料→原料 |
| 红胶储存/使用管理制表 | 红胶储存/使用管理表 | 错别字修正 |

## 六、扩展与覆盖
`scripts/normalize_forms.py` 内置上述默认规则，同时支持通过 `--rules rules.json`（格式 `{"原表单名":"新表单名"}`）与 `--semantic sem.json`（格式 `{"原表单名":"语义类别"}`）覆盖或扩充，适配不同客户的表单命名习惯。
