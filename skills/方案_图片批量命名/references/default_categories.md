# 默认类别清单（制造 / MOM 行业）

当用户未提供自定义类别清单时，使用以下默认类别。类别命名应贴合现场照片的常见内容维度，既覆盖生产现场，也覆盖质量、仓库、文档等。

## 一、生产现场类
| 类别 | 说明 |
|---|---|
| SMT车间 | SMT 产线、贴片机、印刷机、AOI、钢网架、feeder 备料、供料等 |
| 插件车间 / DIP车间 | 插件机（AI/径向/立式）、波峰焊、手工焊、组装流水线、PCBA 在制品 |
| 生产工艺 | 作业指导书(SOP)、操作规程、老化房、包装确认、设备控制、清洗工序等工艺性内容 |
| 检测设备 | LCR、耐压/高压、RoHS(X荧光)、综合测试仪、自动测试系统、视觉检测设备等 |

## 二、仓库与物料类
| 类别 | 说明 |
|---|---|
| 仓库 | 来料/成品堆放区、托盘、缠绕膜等整体仓储场景 |
| 仓库货架 | 重型货架、物料盒货架、PCB 板箱等货架细节 |
| 物料标签 | 储位卡、在制品标识标签、物料标识 |
| 外箱标签 | 来料/出货外箱标签、唛头、产品标签 |
| 物料存储设备 | 防潮柜、冰箱（红胶等）、回温箱等环境控制存储设备 |
| 物料管理表单 | 物料储存/使用管理表、领用记录等 |

## 三、管理与看板类
| 类别 | 说明 |
|---|---|
| 生产管理看板 | 班组看板、精益改善、管理目标、KPI 墙、文件公示墙等 |
| 品质管理看板 | PDCA/8D 工具墙、质量方针、不良统计、客人反馈等 |
| 仓库管理看板 | 仓库人员技能矩阵、仓库管理规则等 |
| 客户需求 | MES/MOM 需求调研、现有系统截图、工序在制报表等客户侧文档 |
| 维修返修工位 | 维修站、返修/维修区 |

|---|---|

| FQC检验表单 | 成品/驱动电源检验报告 |

## 五、设备与环墶类

## 六、扩展说明
- 末尾「等」字允许按实际现场合理扩展或合并类别（例如新增「NCR 报告」「ECN 变更单」等），但应保持命名一致性（名词性、无歧义）。
- 若同一照片既像场景又像表单，优先归入更细化的表单类（如「首件检验记录表」归入 IPQC检验表单 而非笼统的 生产工艺）。
- 无法明确归入任何类别的图片：保留原文件名复制，不在名称上强行归类。
