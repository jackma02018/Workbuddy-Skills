# 批量发票处理 · 字段、归类与校验规则参考

本文件供技能执行时查阅（视觉读取阶段对齐字段与归类口径）。确定性逻辑已由 `scripts/organize.js` 实现；本文件用于**视觉提取阶段**统一字段定义与分类标准。

## 提取字段规范（canonical，脚本与读图须保持一致）

| 字段 | 含义 | 说明 |
|---|---|---|
| source_file | 来源文件名 | 自动填入 |
| page | 页码 | 多页 PDF 时填写，单页/图片填 1 |
| invoice_code | 发票代码 | 10/12 位；全电发票为空 |
| invoice_number | 发票号码 | 8 位（全电发票 20 位） |
| invoice_date | 开票日期 | YYYY-MM-DD |
| invoice_type | 发票类型 | 见第四节 |
| buyer_name / buyer_tax_id | 购买方名称 / 税号 | |
| seller_name / seller_tax_id | 销售方名称 / 税号 | |
| amount_ex_tax | 金额（不含税） | 2 位小数 |
| tax_amount | 税额 | 2 位小数 |
| total_amount | 价税合计 | 2 位小数 |
| tax_rate | 税率 | 如 13%、9%、6%、3%、1% |
| check_code | 校验码 | 后 6 位即可 |
| remarks | 备注 | 备注栏内容 |
| reimbursement_person | 报销人 | 优先从文件名/目录名提取 |
| expense_category | 费用类型 | 见第二节（脚本也会自动归类） |

## 异常检测标准

| 异常项 | 触发条件 |
|---|---|
| 金额不一致 | amount_ex_tax + tax_amount ≠ total_amount（允许 0.01 误差）；铁路/公路客票标记「免校验」 |
| 疑似重复 | 发票代码+号码相同；全电发票仅号码相同（≥20 位） |
| 税率为 0 | tax_rate = 0% 且非免税类型 |
| 金额异常大 | 单张价税合计 > 100,000 元 |
| 日期异常 | 开票日期距今 > 1 年，或在未来 |
| 连号发票 | 同一发票代码下号码连续 ≥ 3 张 |
| 销售方相同 | 同一销售方开出 ≥ 5 张发票 |

## 发票类型识别规则

| 类型 | 识别依据 |
|---|---|
| 增值税专用发票 | 代码以 01 开头，或标题含「专用发票」，有抵扣联 |
| 增值税普通发票 | 代码以 04/10 开头，或标题含「普通发票」 |
| 增值税电子普通发票 | 代码以 04 开头，或标题含「电子」 |
| 全电发票 | 无发票代码，仅有 20 位号码，标题含「全面数字化的电子发票」 |
| 铁路电子客票 | 标题含「铁路」「电子客票」 |
| 公路客票 | 标题含「公路」「汽车客票」 |
| 通行费发票 | 备注含「通行费」或销售方含「高速」「交通」 |

## Excel 明细表列顺序（发票明细工作簿）

序号 → 报销人 → 发票代码 → 发票号码 → 开票日期 → 发票类型 → 购买方名称 → 购买方税号 → 销售方名称 → 销售方税号 → 费用类型 → 金额(不含税) → 税率 → 税额 → 价税合计 → 所属部门 → 所属项目 → 报销月份 → 是否重复 → 金额校验 → 文件名金额核对 → 异常标记 → 备注 → 校验码 → 文件名

## 附件提交建议（可提示用户）

- 每张发票单独一个文件；合并 PDF 中夹杂非发票页会增加漏提风险。
- 优先提供含文本层的电子发票原文件（PDF/OFD/XML）；纯图片 PDF 需走视觉读取或 OCR。
- 标准 A4 纵向完整发票；手机截图可能截断发票号码、校验码。
- 命名建议：`报销人-费用类型-金额-日期-其他.pdf`（如 `报销人-住宿票-300元-5月18日-酒店-其他`），可从文件名直接解析字段。
- 内容纯度：一个文件只放发票，不混入支付凭证、银行通知等。

## 特殊场景处理指南

- 发票图片模糊：尽力补全可识别字段，不明字段标「未识别」。
- 非标准发票（收据等）：正常提取可用字段，费用类型标「其他」，异常标记注「非标准发票」。
- 全电发票（无发票代码）：invoice_code 留空，invoice_number 取 20 位，去重仅用号码。
- 铁路/公路客票无税额：amount_ex_tax = total_amount，tax_amount = 0，金额校验标记「免校验」。
- 纯图片页（无文本层）：用本平台 Read 工具读取图片/PDF 页面，由多模态能力提取字段。
- 非发票页面混入：识别后记录到处理日志，不计入发票。
